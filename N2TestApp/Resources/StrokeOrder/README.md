# Stroke order data

`strokes.json` contains ordered SVG paths and stroke-number positions for every
character used in `N2_vocab.csv`, plus the modern hiragana and katakana sets.
It is generated from [KanjiVG](https://kanjivg.tagaini.net/) data with
`Scripts/generate_stroke_order.py`.
